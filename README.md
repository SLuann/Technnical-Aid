# Technnical-Aid
  Desenvolvimento de um site para Gestão e Empreendedorismo

# Ideia Base
  Site de atendimento/suporte a usuários com serviços WEB, possíveis serviços:
    - Desenvolvimentos de Sites no geral
    - Edição de Softwares
    - Monitoramento e suporte de redes
    - Implementação de Banco de Dados
    - Dúvidas de configuração gerais sobre computadores e celulares
    - Suporte para inicialização de aparelhos
    - Suporte básico

# Linguagens usadas
  - Frontend
      React (.jsx)
  - Backend
      React (.jsx) e JavaScript
  - Banco de Dados
      NEON (bd web)
